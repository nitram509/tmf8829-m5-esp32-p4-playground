Settings

Selects active optical focal plane array resolution (8x8 up to 48x32) and timing profile.
Presets: Fast (590 / ~15 FPS) Balanced (1500 / ~10 FPS) Max Range (3510 / ~5 FPS)
Configures the number of VCSEL laser pulses fired per sub-frame in thousands (kiter × 1024 pulses). Higher values maximize detection distance (up to 5.7 m) and signal-to-noise ratio; lower values reduce integration time for faster frame rates (up to 15–30 FPS). Range: 1–65535 kiter.
Continuously alternates each measurement cycle between standard and high-accuracy modes, merging short-range (<300 mm) accuracy with extended long-range detection into a single combined output frame. Note: Dual Mode 2 (11m Long Range) is exclusive to 8x8 modes.
Presets: Free-running (0 ms) 33 ms (~30 Hz) 66 ms (~15 Hz) 100 ms (10 Hz) 500 ms (2 Hz) 1000 ms (1 Hz)
Target interval between consecutive measurements in milliseconds. Set to 0 ms for free-running capture at maximum achievable frame rate, or higher (e.g. 100 ms) to pace measurements and reduce sensor heating. Range: 0–65535 ms.
Direct Time-of-Flight sensors can detect multiple reflective surfaces along an optical ray (e.g. detecting both cover glass smudges and an obstacle behind it). Reports up to 4 peaks per pixel.
E. ROI / Macro-Pixel Cropping
Restricts active SPAD collection to a rectangular macro-pixel sub-region within the 16x16 sensor array to boost localized frame rate and reduce power consumption (informative placeholder; not active by default).
