TMF8806
=======

If using the TMF8806 integrated ROM version with a maximum 
distance of 5m, no firmware download is required.

Otherwise:

  * Generally all TMF8806 drivers provided by ams-Osram will 
    have latest firmware included. This example uses the Arduino driver.
  * Navigate to https://ams-osram.com/tmf8806
  * Download and unzip TMF8806_Driver_Arduino_v2.12.zip
  * The latest firmware is in
    TMF8806_Driver_Arduino_v2.12\aos_tmf8806_arduino_uno_driver_2v12\how_to_generate_image_from_hex
    filename: mainapp_PATCH_Maxwell.hex
  * For integration with the Arduino driver, the C-version is in
    tmf8806_image.c and tmf8806_image.h
